# Orbit Lens - Demo Flow Lock 23B

## Status

Orbit Lens web demo baseline is ready after the media refresh QA.

The project should now be presented as a premium fictional AI spatial glasses product concept, where the website behaves like the product interface.

Primary demo priority:
- web experience first;
- cinematic Inspect Optics as the main product reveal;
- Field 04 Reference Orbit as the signature interaction;
- Spatial Mode / Quest as an advanced XR proof layer;
- hand-navigation remains experimental and should not be treated as final demo-critical functionality.

---

## Demo Positioning

Orbit Lens is a fictional AI spatial glasses concept and premium interactive product launch website.

Core message:

> A website that behaves like the spatial interface of the product itself.

The demo should show:
- premium product storytelling;
- cinematic shell interface;
- seven product fields;
- optical product inspection;
- spatial reference orbit interaction;
- optional WebXR extension.

Do not present it as:
- a finished hardware product;
- a real commercial device;
- a production-ready VR control system;
- a generic sci-fi dashboard.

### 01 - Opening / Field 01 Vision

### 03 - Field 03 Recall

Move to Field 03.

Show:
- intentional memory logic;
- recall panel;

### 04 - Field 04 Create / Reference Orbit

Move to Field 04.

Show:
- Scroll-Driven Spatial Reference Orbit;
- pseudo-3D floating reference deck;
- active visual note;
- wheel/hover interaction.

Narration:
For creators, Orbit Lens captures references without pulling them out of the moment. The reference deck behaves like a spatial memory field.

Action:
- use wheel to rotate the reference orbit;
- show active card changes;
- this is one of the main signature moments.

---

### 05 - Inspect Optics

From Field 04 or Field 01, open Inspect Optics.

Show:
- cinematic shell zoom;
- smooth opening;
- floating product cards;
- selected / expanded optics card;
- Return / close behavior.

Narration:
Inspect Optics reveals the product layers as a cinematic spatial inspection system. This is the strongest product-detail moment in the web demo.

Action:
- open Inspect Optics;
- click/select one card;
- close expanded card;
- Return to field;
- open again briefly if needed to show repeat stability.

---

### 06 - Field 06 Privacy

Move to Field 06.

Show:
- visible trust state;
- consent / privacy boundary;
- user-controlled memory logic.

Narration:
Trust is part of the interface, not an afterthought. Capture, memory, and context access remain visible to the user.

Action:
- brief pause;
- reinforce that this makes the concept more mature and believable.

---

### 07 - Field 07 Access

Move to Field 07.

Show:
- product / studio access console;
- status rows;
- portfolio / GitHub / contact controls;
- final controlled preview terminal.

Narration:
The experience closes as a controlled product and studio access layer - not a generic contact page.

Action:
- pause;
- show CTA links if needed.

---

### 08 - Spatial Mode / XR Proof

Click Spatial Mode.

Show:
- /spatial route;
- WebXR-ready spatial shell;
- Enter VR option;
- if showing Quest capture: show that it launches in VR and hands appear.

Narration:
Spatial Mode is the optional XR twin of the interface. It proves that the same product system can move from web into a spatial WebXR layer.

Important:
Do not position hand navigation as final. Say it is an experimental interaction layer under development.
